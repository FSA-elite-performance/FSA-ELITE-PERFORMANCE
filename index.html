Authentication, runtimes, and resources

Use this quick reference when choosing an auth strategy, a runtime, or the next piece of documentation to open.

Authentication

  • Vercel OIDC tokens are recommended and automatic in production on Vercel.
  • For local development, run vercel link and vercel env pull to get a development token.
  • Use access tokens when VERCEL_OIDC_TOKEN is unavailable, such as external CI/CD or non-Vercel environments.

System specifications

  • Amazon Linux 2023
  • Runtimes: node24, node22, and python3.13
  • Default runtime: node24
  • User: vercel-sandbox with sudo access
  • Working directory: /vercel/sandbox
