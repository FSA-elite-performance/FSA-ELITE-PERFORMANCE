Page Agent.

The GUI agent living in your webpage. Control web interfaces with natural language using in-page JavaScript, without a browser extension, Python runtime, or headless browser.

View GitHub repo → Read docs Try demo

Open source on GitHub: alibaba/page-agent

Page Agent runs inside the browser page itself, making it a strong fit for SaaS copilots, form automation, and accessibility flows.

Why teams use Page Agent

Bring natural-language automation into existing interfaces without a major rewrite.

🎯

Easy Integration

Add it in-page with JavaScript instead of wiring up an extension, Python worker, or headless browser stack.

📖

Text-Based DOM Control

Automate interfaces from page structure and text rather than relying on screenshots or multimodal models.

🧠

Bring Your Own LLM

Connect the agent to the model provider that fits your product, deployment model, and budget.

🎨

Human-in-the-Loop UI

Keep users in control with an interface that makes automation visible and easy to supervise.

Quick start

Start with the GitHub repo, then follow the docs to embed Page Agent or install the npm package in your app.

Get started

page-agent

  • ✅ Install with npm install page-agent
  • ✅ Configure your model, base URL, API key, and language
  • ✅ Execute instructions like “Click the login button” in the page
  • ✅ Use the optional extension for multi-page tasks
