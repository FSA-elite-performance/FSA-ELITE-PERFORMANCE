# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by opening a [new private security advisory](https://github.com/FSA-elite-performance/FSA-ELITE-PERFORMANCE/security/advisories/new).

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

We will review reports as quickly as possible and coordinate remediation before public disclosure.

## Supported Versions

This repository supports security fixes on the current `main` branch.
